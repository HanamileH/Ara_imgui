# Widget cheat sheet
This page provides a brief overview of the main widgets available in the Ara_imgui library. All widgets are divided into categories for ease of search and use. For more detailed information about each widget, please refer to the appropriate section of the documentation.

### Text displaying

| Widget | Description |
|--------|-------------|
| [imgui.text](widgets/text.md) | Displays a simple text label. |
| [imgui.text_colored](widgets/text_colored.md) | Displays a text label with a custom color. |
| [imgui.text_disabled](widgets/text_disabled.md) | Displays a text label with a disabled appearance. |
| [imgui.text_wrapped](widgets/text_wrapped.md) | Displays a text label with word wrapping. |
| [imgui.text_link](widgets/text_link.md) | Displays a text label with a hyperlink appearance. |
| [imgui.text_link_open_url](widgets/text_link_open_url.md) | Displays a text label with a hyperlink appearance that opens a URL when clicked. |

### Buttons

| Widget | Description |
|--------|-------------|
| [imgui.button](widgets/button.md) | Creates a clickable button. |
| [imgui.radio_button](widgets/radio_button.md) | Creates a radio button for selecting one option from a group. |
| [imgui.checkbox](widgets/checkbox.md) | Creates a checkbox for toggling a boolean value. |

### Inputs

| Widget | Description |
|--------|-------------|
| [imgui.input_int](widgets/input_int.md) | Creates an input field for entering an integer value. |
| [imgui.input_float](widgets/input_float.md) | Creates an input field for entering a floating-point number. |

### Structuring

| Widget | Description |
|--------|-------------|
| [imgui.separator](widgets/separator.md) | Creates a horizontal separator line. |
| [imgui.begin_child](widgets/child.md) | Creates a child window or a scrollable region. |
